# Compositional Degree and Mixed-Norm Bounds for Conjunctive Queries

ICDE 2027 research paper supplemental material. This package contains the estimator implementation, experiment drivers, public dataset download instructions, and the final tables and plot inputs.

| Directory | Contents |
| --- | --- |
| `src/cqnorm/` | Degree and mixed-norm statistics, compositional propagation, Shannon and Flow solvers, and numerical certificate checks |
| `experiments/` | Workload construction, data preparation, independent DuckDB ground truth, benchmarks, and figure generation |
| `configs/` | Dataset URLs |
| `results/paper/` | Reported aggregates and selected per-query and per-consumer measurements |
| `docs/references/` | Published JOBlight truth and estimates with upstream attribution |

## Setup

The reported experiments used Python 3.11.18, DuckDB 0.10.1, and OR-Tools 9.12.4544 with one GLOP thread. Use a Python 3.11.18 virtual environment and install the pinned packages.

```sh
python -m pip install -r requirements.txt
```

From the artifact root, clone LpBound into the sibling directory `../LpBound`. The experiments use its workloads and the upstream Python Berge solver. LpBound is distributed under its upstream MIT license.

```sh
git clone --depth 1 --filter=blob:none --sparse https://github.com/fdbresearch/LpBound.git ../LpBound
git -C ../LpBound sparse-checkout set src/lpbound/config src/lpbound/acyclic src/lpbound/duckdb_adapter src/lpbound/solver src/lpbound/utils benchmarks/schemas benchmarks/workloads/jobjoin benchmarks/workloads/joblight benchmarks/workloads/stats data/sql_scripts/duckdb
```

Run a small solver and DuckDB example from the artifact root.

```sh
python experiments/smoke_lpbound.py
```

## Download the datasets

```sh
python experiments/prepare_artifact_data.py
```

The script downloads [IMDb JOB Parquet](https://huggingface.co/datasets/liangyc/job) to `data/imdb_job/` and [STATS-CEB simplified CSV files and schema](https://github.com/Nathaniel-Han/End-to-End-CardEst-Benchmark/tree/master/datasets/stats_simplified) to `data/stats_ceb/datasets/stats_simplified/`. Use `--dataset imdb` or `--dataset stats` for one dataset. Use `--plan` to list the URLs and file destinations for manual download. Synthetic data are generated by the experiment scripts.

## Read the reported results

`summary_metrics.csv` contains the experiment-level aggregates. For long-format files, `metric` is the field path and `value_json` encodes the scalar value.

| Experiment | Result files under `results/paper/` |
| --- | --- |
| Workload coverage, cardinality ablation, and phase times | `summary_metrics.csv`, `ablation_imdb_queries.csv`, `ablation_stats_queries.csv` |
| Matched depth and projection diagnostic | `matched_depth_queries.csv`, `plot_depth.csv`, `plot_projection.csv` |
| Mixed-norm holdout and synthetic separation | `mixed_holdout.csv`, `summary_metrics.csv` |
| STATS reuse and fixed certificates | `plot_reuse.csv`, `certificate_comparison.csv`, `summary_metrics.csv` |
| Crossing keys and scaling | `plot_crossing_scale.csv`, `crossing_scale.csv`, `shape_scale.csv` |
| End-to-end STATS execution | `end_to_end_consumers.csv`, `end_to_end_paired.csv`, `summary_metrics.csv` |
| Diamond refresh, solver agreement, Berge and JOBlight | `summary_metrics.csv`, `matched_berge_queries.csv` |

Regenerate the four PGFPlots definitions directly from the published CSVs.

python experiments/render_diagnostic_plots.py --paper-results results/paper diagnostic_plots.tex

## Re-run the experiments

After setup and data download, run from the artifact root.

```sh
python experiments/reproduce_paper.py
```

The runner chains the experiments in dependency order and writes fresh table data to `results/reproduced/`. The driver names and parameters are listed in [reproduce_paper.py](experiments/reproduce_paper.py). For individual drivers, add `src` to `PYTHONPATH` from the artifact root. Each driver has its own `--help` and writes a dated run directory. Large IMDb joins can use substantial disk space for temporary DuckDB spill files. Performance measurements depend on hardware and load. The recorded environment for the final diagnostic runs was Windows build 26200, AMD Ryzen 9 7945HX, and 16 GiB RAM.

The main workloads use set semantics. The same-input Berge comparison and upstream JOBlight replication use bag row counts. Exact DuckDB counts and degree statistics are used for ground truth. The paper reports successful verified bounds separately from SQL timeouts and unavailable profiles.
